# A+B 联合广义标度律报告

生成日期：2026-09-26

## 结论先行

已完成一个内部联合模型和隐藏反馈评测闭环。B-only 基线保留不变，A 侧通过显式 `p` 适配器接入，A/B 不按行拼接。最终候选的隐藏反馈聚合分数为 **0.910020**；相对于首版 `0.882834` 和一次未通过规模校准的 `0.872188`，当前版本提升后冻结。

这个分数是允许多轮聚合反馈后的结果，不能表述为完全未污染的独立测试成绩。A12-A15、B8、B9、B10 的外推/压力结果不并入主模型合格分。

## 模型和数据

### A 侧

- A1-A3 通过原问题一管线复现质量代理分 `Q_A`。
- A4-A5 用 512 组 1M 配方和 13 维 Loss 拟合配比函数 `A_M2(p)`。
- A6-A9 用 1M/60M 的 512 行开发验证跨规模迁移。
- A10-A11 是 1B 隐藏反馈集，共 64 行。
- A12-A15 是 10B/70B 外推压力集，共 126 行。

### B 侧

- B1 和 B6 作为拟合数据，共 1,536 行。
- B2/B3 作为开发反馈，不把 Cerebras 半合成轨迹或 Pythia 插值轨迹描述成独立真实观测。
- B4/B5 作为隐藏反馈，分别保留跨族和文献来源。
- B8 的 `calibrated` 与 `extrapolated` 分开统计。
- B9 只做可预测覆盖检查；B10 是估算 Loss 对照，不是真实训练观测。

## 诚实限制

- B2 的绝对 Loss 有 Cerebras 模型族偏移，不能把它当成 B1 同分布误差。
- B8 的质量方向在 `extrapolated` 子集出现异常，不能强行并入 B6/B7 训练。
- A12-A15 是外推/估算性质，当前结果不能证明 10B/70B 上的配比因果效应。
- 当前联合接口仍是内部实现，未修改既有 `INTERFACE.md` 和最终 A 公开接口。
