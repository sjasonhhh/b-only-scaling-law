# A+B 数据划分与防泄漏清单

生成日期：2026-09-26

## 1. 数据来源与字段边界

问题二使用问题一已经生成的派生结果，不在联合模型中重新读取 A1-A3 原始质量文本。A 侧派生结果由 Q1 管线从 A1-A3 去重质量信号、A16 域映射和 A4-A15 配方/Loss 表生成。

- A 派生字段：`N_params_B`、`p_1...p_17`、`Q_A`、`L_A_domain_1...L_A_domain_13`、`L_A_macro`。
- B 观测字段：`N_params_B`、`D_tokens_B`、`Q_score`、`val_loss`。
- A 没有真实 `D_tokens_B`，不填 0；B 没有配比 `p`，不填均匀向量。
- A 与 B 没有共同实验主键，不按行拼接；联合关系通过显式的配比适配器连接。

Q1 本次复现得到 272,505 条原始质量记录、261,086 个去重文档，Q 的范围为约 `[0.2540, 0.7778]`。A16 中 7 个域可以直接或近直接映射到质量域，其余 11 个域使用等域先验，不把先验伪装成直接观测。

## 2. 固定划分

| 角色 | A 数据 | B 数据 | 用途 |
|---|---|---|---|
| 训练/拟合 | A4-A5，512 行 | B1，1,176 行；B6，360 行 | 拟合主模型和配比适配器 |
| 开发验证 | A6-A9，512 行 | B2，1,029 行；B3，4,000 行；B7 新增 90 行 | 模型选择、结构检查和跨轨迹反馈 |
| 隐藏反馈 | A10-A11，64 行 | B4，57 行；B5，44 行 | 标签隔离，只返回聚合分数和诊断 |
| 压力/外推 | A12-A15，126 行 | B8，1,704 行；B9，132 行；B10，128 行 | 单独报告，不计入主模型合格分 |
| 元数据 | 无 | B11、B12 | 追溯和覆盖检查，不作 Loss 监督 |

A6 与 A8 使用相同的 256 个配比指纹，但对应不同规模，所以只能作为跨规模验证，不能当作 512 个独立配方。A12 与 A14 共享 63 个配比指纹，且这 63 个配方来自训练配方子集，因此只能用于外推压力说明。

## 3. B 组重复和谱系

- B6 与 B7 有 360 个完全重复的 `(N_params_B, D_tokens_B, Q_score)` 条件；B7 只有新增 90 行进入开发验证。
- B7 与 B8 按数值规范化后有 32 个共同 `(N_params_B, D_tokens_B)` 条件，对应 B8 的 288 行；其中 224 行与 B7 的完整三元条件重合。
- B8 的 `calibrated` 984 行和 `extrapolated` 720 行分开评估。
- B3 是由 Pythia 检查点插值得到的轨迹；同一模型轨迹内的行共享 `lineage_group`，禁止随机打散后宣称独立验证。
- A 的 `index` 只在同一配方表和对应 Loss 表内有效，不能作为跨文件主键。

## 4. 防止过拟合的规则

1. 不按行随机切分；优先按完整配比指纹、实验条件、模型族、训练轨迹和生成谱系分组。
2. 训练阶段不读取 A10-A11、B4、B5 的标签。
3. A12-A15、B8、B10 不用于本版本拟合或参数选择；它们只能作为压力/外推结果。
4. 每次提交保存模型哈希、代码状态、数据 manifest 哈希和聚合评测分数。
5. 隐藏评测器不返回单行标签、单行残差或可逆推出标签的排序信息。
6. 失败版本不删除；最终报告同时保留 `submission_000`、`submission_001`、`submission_002` 和 `submission_003` 的聚合反馈历史。
7. 由于允许使用聚合反馈迭代，最终结果称为“隐藏反馈评测结果”，不称为完全未污染的独立测试成绩。

## 5. 当前联合模型的边界

联合模型为内部版本：

```text
B: L_B(N,D,Q) + gamma(N) * (A_M2(p) - A_M2(p_reference))
A: A_M2(p) + scale_offset(N)
```

配比修正只在 A 的已观测开发规模范围内完整使用；超过 60M 后收缩为 0.25，避免把 1M/60M 的配比效应未经验证地线性外推到 1B、10B 和 70B。该收缩参数由开发过程冻结，并通过隐藏评测的聚合分数选择，未读取隐藏行级标签。
